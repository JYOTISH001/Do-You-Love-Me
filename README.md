# ❤️ Love Story — An Interactive Romantic Experience

> **A little website made with a lot of love. 💌**

An interactive and cinematic romantic web experience designed to turn a simple question into a memorable journey.

It starts with a beautiful welcome screen, leads into a playful **"Do You Love Me? ❤️"** interaction, and continues through a personalized love letter, memories, reasons, and a final emotional message.

* 💖 Premium romantic UI

## 💫 The Experience

The website is designed as a small romantic journey rather than a traditional website.

### 01 — Welcome ❤️

A cinematic loading experience welcomes the visitor with glowing hearts, romantic messages and a smooth transition.

### 02 — The Question 🥺

> **Do You Love Me? ❤️**

The visitor gets two choices:

**YES ❤️**
**NO 🥺**

The NO button has a playful interaction, while the YES button leads to the main celebration.

### 03 — Love Reveal 💕

A heart-filled celebration reveals:

> **I KNEW IT! ❤️**

### 04 — Love Letter 💌

A beautiful digital letter opens with a personalized romantic message.

### 05 — Memories 📸

A collection of photos and memories can be added to create a personalized gallery.

### 06 — Reasons ❤️

Interactive cards showcase the little things that make someone special.

### 07 — Our Story 🕰️

A timeline presents important moments and memories.

### 08 — Forever ∞

The experience ends with a cinematic final message:

> **I LOVE YOU ❤️**

## ⚙️ Customization

The experience can easily be personalized.

You can customize:

* ❤️ Person's name
* 💌 Love letter
* 📸 Photos
* 📝 Memories
* ✨ Reasons
* 🕰️ Timeline
* 🎵 Music
* 💕 Final message

Example configuration:

```ts
const LOVE_CONFIG = {
  personName: "NUNA",
  yourName: "JOY",
  photos: [],
  memories: [],
  reasons: [],
  timeline: [],
  musicUrl: ""
};
```

Replace the placeholder values with your own content.

## 🚀 Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate into the project:

```bash
cd YOUR_PROJECT_FOLDER
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in your terminal.
